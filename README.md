# ☕ Java Programming I — University of Helsinki

Repositório com os exercícios desenvolvidos durante o curso **Java Programming I**, oferecido pela **University of Helsinki**.

O curso tem como objetivo desenvolver uma base sólida em programação utilizando Java, passando por conceitos fundamentais de lógica, estruturas de controle, métodos e programação orientada a objetos.

Este repositório serve como registro do meu processo de aprendizagem e evolução com a linguagem Java.

## 📚 Sobre o curso

O **Java Programming I** é um curso introdutório de programação que utiliza Java para desenvolver conceitos fundamentais de programação e resolução de problemas.

Durante os exercícios, são trabalhados conceitos progressivamente mais complexos, permitindo construir uma base para estudos posteriores em **Programação Orientada a Objetos** e desenvolvimento de aplicações Java.

## 🧠 Conteúdos praticados

Entre os principais conceitos presentes nos exercícios estão:

* Variáveis e tipos de dados
* Entrada e saída de dados
* Operadores
* Estruturas condicionais
* Estruturas de repetição
* Métodos
* Parâmetros e valores de retorno
* Processamento de números
* Manipulação de Strings
* Lógica de programação
* Resolução de problemas com Java
* Princípios iniciais de Programação Orientada a Objetos

## 🚀 Como executar

### 1. Pré-requisitos

É necessário ter o **JDK (Java Development Kit)** instalado.

Verifique a instalação:

```bash
java --version
```

### 2. Clone o repositório

```bash
git clone https://github.com/ricfmf/Java-1-Helsink.git
```

### 3. Acesse o exercício desejado

Entre no diretório correspondente ao exercício que deseja executar.

### 4. Compile e execute

Exemplo:

```bash
javac Main.java
java Main
```

A forma de execução pode variar de acordo com a estrutura de cada exercício.
